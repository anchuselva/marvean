# MARVEAN // AI Model Optimization & Autonomous Decision Engine

An interactive, retro 16-bit arcade cyber styled AI model optimization and autonomous decision engine web experience.

## Features
- **FP8 & INT4 Dynamic Quantization**: Visualizing tensor activation profiling and memory reduction.
- **Autonomous Decision Engine**: Sub-millisecond query arbitration layer and model routing.
- **Hardware-Aware Kernel Fusion**: Benchmarks for FlashAttention-3 and Triton kernels.
- **Interactive Simulator & Developer SDK**: Live terminal benchmarks and multi-language code integration examples.
- **Built-in Web Audio API**: Retro 8-bit sound synthesizer with CRT screen effects.

## Quick Start

### Run with Node.js
```bash
node server.js
```
Open [http://localhost:3000/](http://localhost:3000/) (or the next available port) in your browser.

## Tech Stack
- Vanilla HTML5 & CSS3 (Custom Retro Arcade Cyber Design System)
- Vanilla JavaScript & Web Audio API
- Node.js zero-dependency HTTP static server
